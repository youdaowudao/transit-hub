# 用户最后使用改用邮箱

状态：已完成。

## 目标

- “用户最后使用记录”按 Sub2API 用户的完整邮箱地址展示和复制，不再依赖可为空的用户名。
- 复制成功后让当前行永久保留“已复制”状态和成功色，刷新、重新查询或离开后再返回仍然保留；复制按钮始终保持可重复操作。

## 实际改动

- 确认实际 Sub2API `users` 表包含非空 `email` 与 `username` 两列，现有管理接口将 `users.email` 映射为用户 JSON 的 `email` 字段。
- 用户最后使用记录的归组、表格显示和复制内容全部改用完整邮箱；用户名为空但邮箱存在的用户不再被漏掉。
- 已复制用户按用户 ID 与邮箱写入浏览器本地存储，刷新、重新查询或离开后再返回仍显示淡绿色背景和“已复制”；复制按钮始终保留，可重复复制。
- 内置版本同步到 `V2.1.20`。

## 验证

- `npm run typecheck`：通过。
- `npm run build`：通过；仅有依赖包 `@vueuse/core` 的既有 Rollup 注释警告。

- 浏览器请求只有 GET，控制台无错误或警告；Playwright、Vitest、类型检查和构建进程及临时文件均已回收。
