# 变更排队

当前版本基线：`V2.3.0`

本文件是需求与变更的唯一排队、状态和交接入口；详细需求、计划和验证仍以各变更目录内的文件为准。

## 使用方法

1. 代码工作开始前必须先查看本文件；从“当前排队”领取“待开发”任务后，立即改为“开发中”。
2. 文档工作结束前必须回到本文件增加任务：文档未完成时登记到“未排队需求”；文档完成时在“当前排队”新增一项“待开发”任务。文档工作只增加任务，不直接消耗任务。
3. 代码工作结束前必须回到本文件交任务：完成时将已领取任务从“当前排队”移到文末“已完成”，补上完成版本和验证文档；未完成时按实际情况交接或暂停。代码工作负责消耗任务。
4. 暂停时，任务仍留在“当前排队”并改为“暂停”，写明恢复条件。除非用户明确允许并行，同一时刻只能有一个“开发中”任务；“待开发”从上到下为默认顺序。
